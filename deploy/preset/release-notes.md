# 3X-UI 3.10.2 IPv6 + HY2 默认节点版

基于 3X-UI v3.10.2，Xray 内核继续固定为 **v26.6.27**。独立分支 `codex/v3.10.2-preset-ipv6-hy2`，独立标签 `v3.10.2-preset-ipv6-hy2`。旧 `v3.10.2-preset`、v3.6.0 视频版及其安装包保持不变。

## 一键部署

在 Linux VPS 上以 root 执行：

```bash
bash <(curl -fLsS https://raw.githubusercontent.com/kjxv-1/3x-ui/v3.10.2-preset-ipv6-hy2/deploy/preset/install.sh)
```

安装包、面板、安装脚本和管理脚本来自 `kjxv-1/3x-ui` 的本标签，下载后强制验证 SHA256。包内包含校验过的固定 Xray 内核。

## 首次部署生成的节点

| 名称 | 配置 | 默认出站 |
| --- | --- | --- |
| IPv4-直连 | VLESS + TCP + REALITY / Vision，IPv4 分享地址 | VPS 直连 |
| IPv6-直连 | VLESS + TCP + REALITY / Vision，IPv6-only 监听，独立 IPv6 分享地址 | VPS 直连 |
| Hy2-直连 | Hysteria 2 + QUIC/UDP + TLS | VPS 直连 |
| 住宅-待配置 | VLESS + TCP + REALITY / Vision | 住宅 Socks5 出站“默认” |

四个入站共用一个邮箱为 **01** 的客户端及同一订阅 ID。UUID、HY2 认证密码、各 REALITY 密钥及 Short ID 都随机生成。VLESS 最小客户端版本为 1.0.0。订阅服务及 Clash/Mihomo 订阅默认开启，节点备注不含个人名称。

REALITY 继续使用面板的目标扫描器，筛选可用的非微软候选，再选延迟较低的目标。客户端 SNI 只包含选中的域名。HY2 不使用 REALITY 或该 SNI，它使用 TLS 证书所覆盖的名称。

### 订阅流量和到期提示

默认开启“独立信息配置 / 提示节点”，备注模板固定为：

```text
{{INBOUND}} | 📊 剩余流量：{{TRAFFIC_LEFT}} | 📅 到期：{{EXPIRE_DATE}}
```

客户端配置流量限额或到期时间后，普通 Base64 订阅（包括 v2rayN）、JSON 和 Clash/Mihomo 订阅会在顶部增加一条显示剩余流量及到期日期的信息节点。有效订阅的信息节点复制该格式下第一条实际节点的完整连接配置，仅替换名称，因此可以正常连接和测试真实延迟，不依赖 `127.0.0.1:1080`、`10808` 或客户端的本地端口。延迟反映所复制线路的实际状态，线路不可达时仍会失败；测速和连接流量计入同一客户端额度。不会新增面板入站、客户端或独立流量额度。四个实际节点的名称和排序保持不变，Clash/Mihomo 的默认选择仍是原实际节点，信息节点也可在代理组中选择和测速。

余额在更新订阅时刷新。仅设置其中一项时，只显示已配置的信息；两者都未设置时，不额外生成空提示项。默认客户端仍为无限流量、无到期时间。订阅过期或流量耗尽时，仅返回不可连接的状态提示，不复制真实连接。

这些默认值只在首次空面板部署时写入。已有面板升级不会覆盖用户的模板或开关；已开启信息节点的面板升级后，更新订阅即可取得新版可测速的信息节点。需要时，可在“面板设置 → 订阅设置”中启用该开关并填写上述模板。

### IPv6 条件

自动选择服务器已启用网卡上的公网 IPv6，排除 `fe80::`、`fd00::`、回环和 IPv4。分享地址不会误用登录面板时的 IPv4。VPS 必须事先由服务商和操作系统配置好 IPv6；此安装器不会替你创建 IPv6 隧道、修改系统网络或自动开通服务商地址。

若未发现公网 IPv6，仍创建该入站，但**禁用并从订阅排除**，在安装结果中明确提示。完成服务器 IPv6 配置后，在面板填写真实的 IPv6 分享地址、启用入站并取消“从订阅中排除”。使用 IPv6 节点的电脑或手机也必须有可用的 IPv6 网络。IPv6 接入不强制改变网站最终看到的出口地址族。

### 自动申请 IPv4 / IPv6 证书

选择默认的 Let's Encrypt IP 证书方式时，安装器自动检查已启用网卡上的稳定公网 IPv6。有 IPv6 时，把 IPv4 和选中的 IPv6 一起写入同一张证书；没有 IPv6 时，仅申请 IPv4。不再要求手动填写 IPv6。排除链路本地、ULA、文档、临时、暂定、弃用和地址冲突的地址。指定预设 IPv6 时优先使用该地址，自动检测时也让默认 IPv6 节点与证书使用同一地址。

面板和订阅服务使用相同的证书文件，原有证书续期继续自动执行；IP 短期证书每 3 天尝试续期。申请前更新 acme.sh，以支持 IPv4/IPv6 双栈 HTTP-01 验证。**所有申请地址的公网 TCP 80 都必须能被证书机构访问**；仅检测到地址并不保证签发成功。IPv6 验证失败会明确报错，不静默移除 IPv6，也不删除已安装的证书。安装阶段校验证书有效期、IP SAN 和私钥匹配，失败时恢复原文件。

已有面板升级时保留证书和节点，不会强制重签。若现有证书仅包含 IPv4，升级后运行 `x-ui`，选择「SSL Certificate Management」→「Let's Encrypt SSL Certificate for IP Address」，重新申请；管理菜单同样会自动包含 IPv6。确认订阅服务使用生成的 `/root/cert/ip/fullchain.pem` 和 `/root/cert/ip/privkey.pem`，保存并重启面板。IPv6 订阅地址使用 `https://[公网IPv6]:订阅端口/原订阅路径/订阅ID`；证书更新不会自动更改客户端中已保存的订阅 URL。

### HY2 条件

HY2 复用安装时配置的面板 TLS 证书及密钥文件，SNI 从证书覆盖的域名或 IP 中选择，保持正常证书校验，不生成跳过验证的订阅配置。证书续期继续使用现有文件及面板的重启机制。

默认安装流程申请 IP 证书或配置有效域名证书后，HY2 自动启用。若选择跳过 TLS，HY2 入站会禁用并从订阅排除，其他节点照常创建。后续可在该入站的安全设置中选择有效证书和对应 SNI，再启用并取消订阅排除。证书文件存在但无效、过期或密钥不匹配时，首次初始化明确报错并回滚，保留待重试标记。

### 端口与住宅出站

四个节点选择互不重复的随机空闲端口；VLESS 检查 TCP 占用，HY2 检查 UDP 占用。请在 VPS 防火墙和云安全组按安装结果放行：**VLESS 是 TCP，HY2 是 UDP**，同时保留面板和订阅端口。安装结果写入 `/etc/x-ui/preset-result.json`，权限 600，含新增端口及启用状态。

住宅节点沿用原版设置：登录后编辑 Xray 出站“默认”，填写住宅 Socks5 地址、端口和认证信息。未填写或不可达时，住宅节点失败，不回退到 VPS 出口；其他直连节点独立使用。供应商采用 IP 白名单时，将 VPS 的相应出口 IP 加入白名单。

## 可选参数

- `XUI_SSL_IPV6`：默认 `auto`，自动将公网 IPv6 加入 IP 证书；设为 `none` 仅申请 IPv4，或填写已配置在活动网卡上的公网 IPv6。自定义地址不能带方括号、端口、掩码或区域编号。
- `XUI_PRESET_PUBLIC_ADDRESS`：IPv4 节点和 HY2 的分享地址，可为 IP 或域名。
- `XUI_PRESET_IPV6_ADDRESS`：明确指定服务器的公网 IPv6，不能带方括号、端口、`/64` 或 `%接口编号`；须由你确保该地址已配置可用。
- `XUI_PRESET_DIRECT_PORT`、`XUI_PRESET_RESIDENTIAL_PORT`：原有 VLESS TCP 端口。
- `XUI_PRESET_IPV6_PORT`：新增 IPv6 VLESS TCP 端口。
- `XUI_PRESET_HY2_PORT`：HY2 UDP 端口。
- `XUI_PRESET_REALITY_SERVER_NAME`：指定已验证可用的非微软 REALITY 目标，跳过自动扫描。

## 按备注批量保存订阅顺序

入站列表顶部新增「订阅排序」按钮。点击后选择「正序」或「反序」，核对备注、原序号和新序号，再点「保存订阅顺序」。数字采用自然排序（例如 2 在 10 前），同名按 ID 排序；反序将整个顺序反转。批量设置范围为当前面板的全部入站，包含被搜索或节点筛选隐藏的入站，保存为连续的 1、2、3…。表头箭头仍只调整面板显示，需使用此按钮才能保存客户端订阅顺序。

保存后，在 v2rayN、Clash/Mihomo 等客户端更新订阅。该操作只修改订阅排序，不改端口、协议、客户端或流量额度，不需要重启面板。预览后列表有变化时会要求刷新预览；如果保存中断，界面提示已确认的成功数量，请刷新预览后再重试。不要在保存过程中关闭页面。

功能保存在本仓库源码和本标签的安装包中，无须再粘贴浏览器控制台脚本。已有面板需先使用本页的一键部署命令升级（保留现有配置），然后强制刷新浏览器页面即可看到入口。后续仍使用同一个标签和部署命令。

## 已有面板和升级

预设只在首次空面板安装时执行，创建记录、路由、客户端、设置和完成标记在同一事务内提交。失败可修复后重试。

**在已有面板上运行新版安装器会保留已有配置，不自动追加节点。** 旧预设的完成标记同样受保护；已删除节点不会被重新创建，订阅 ID、UUID、住宅认证和用户修改不会被重置。本标签用于新部署时自动得到四个节点。

## Docker

```bash
docker build -t ghcr.io/kjxv-1/3x-ui:v3.10.2-preset-ipv6-hy2 https://github.com/kjxv-1/3x-ui.git#codex/v3.10.2-preset-ipv6-hy2
docker run -d --name 3x-ui --network host --cap-add=NET_ADMIN --cap-add=NET_RAW -v "$PWD/db:/etc/x-ui" ghcr.io/kjxv-1/3x-ui:v3.10.2-preset-ipv6-hy2
```

容器首次启动没有证书时，HY2 保留为待配置状态。容器使用 HY2 时，需要持久挂载有效证书文件，并在面板设置对应路径和 SNI。
